````markdown
# ✅ Form Validation Website

A simple and responsive website that demonstrates real-time form validation using **HTML**, **CSS**, and **JavaScript**. This project helps beginners understand how to validate user inputs on the client side before form submission.

---

## 🧠 Features

- Real-time input validation
- Email format checker
- Password strength rules (length, characters)
- Required field checks
- Clear error messages
- Mobile-friendly design

---

## 💻 Technologies Used

- **HTML5** – form structure and input fields  
- **CSS3** – styling and layout  
- **JavaScript** – input validation and user feedback

   ```bash
````
